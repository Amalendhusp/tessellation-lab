About

Tessellation: develop a figure that repeats across the plane, in four stages.

Polygon · choose a starting shape (Tri triangle, Quad quadrilateral, starting as a square; Hex hexagon comes later) and a construction method: Translate, Rotate, Glide reflection, Reflection, or Figure & Ground (two complementary figures). On Quad, move corners and add points on the sides (up to 40). Every change is copied to the matching side, so the tile always fits its neighbours. How tiles repeat ›
Shape · pull the sides into curves; sketch your idea.
Illustrate · draw, fill, add dots and textures; with Reflection, draw symmetrically if you like.
Tessellate · see the pattern, colour groups of tiles, set the outline.

Unfinished work is kept on this device automatically, one piece at a time: the start screen offers to Continue it. Save to Gallery keeps a project in My Gallery (only what you save yourself), with a picture of its tile and its pattern. Open… shows the same Gallery and can import a project file; Save as file… makes a file you can move to another device or hand in. Backup / Restore saves the whole Gallery in one file and brings it back. Export… makes a picture (PNG or SVG). Test mode comes in a later version.

Two fingers move and zoom. Work kept in Safari and in a Home Screen copy of the app are kept separately: use Save as file or a Gallery backup to move work between them. Version v5.11 (Phase 2): My Gallery, Open and Import, Backup / Restore. Earlier: v5.10 (Phase 1): starting shapes Tri · Quad · Hex, the construction methods Translate · Rotate · Glide reflection · Reflection · Figure & Ground, Undo and Redo together in every stage, and a simpler menu. Earlier: v5.9 Figure & Ground · Reflection and per-figure colours; v5.8 Figure & Ground; v5.7 the two Reflection arrangements; v5.6 Reflection.

Back up

One file with every project saved in My Gallery, complete and editable: shape, construction, drawing, fills, figure colours and reference photo. Save it to Files or Downloads.

Unfinished work that is only kept automatically is not included, only projects saved to My Gallery.

Restore

Adds the projects from a backup file to My Gallery. You see them first. Nothing in My Gallery is replaced unless you choose to and confirm.

Each web address keeps its own Gallery. A backup moves projects between devices, addresses and app versions.
