# Tessellation

A classroom web app for making Escher-style tessellations on a phone: develop a figure on a polygon, refine it, illustrate it and repeat it across the plane.

**Open it:** https://amalendhusp.github.io/tessellation-lab/

* Works in Safari on iPhone and iPad, and in current desktop browsers. Nothing to install.
* Your work is kept **only on your own device**, in this browser. Nothing is uploaded and no account is needed.
* Use **⋮ › Save project** to keep a copy as a file, and **⋮ › Save image** for a PNG or SVG picture.

Built for the Geometry 2D course (Foundation Programme, NIFT).
