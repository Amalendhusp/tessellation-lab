# Tessellation

A classroom web app for making Escher-style tessellations on a phone: choose a starting shape and a construction method, develop the figure, illustrate it and repeat it across the plane.

**Open it:** https://amalendhusp.github.io/tessellation-lab/

* Works in Safari on iPhone and iPad, and in current desktop browsers. Nothing to install.
* Your work is kept **only on your own device**, in this browser. Nothing is uploaded and no account is needed.
* Unfinished work is kept automatically; **☰ › Save to Gallery** keeps a project in **My Gallery**.
* **☰ › Backup / Restore** saves the whole Gallery as one file (for example to Files) and brings it back; **Save as file…** makes a single project file to hand in; **☰ › Export…** makes a PNG or SVG picture.

Built for the Geometry 2D course (Foundation Programme, NIFT). Version v5.11 (Phase 2).
